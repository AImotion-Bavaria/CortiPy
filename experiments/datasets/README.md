# Synthetic dataset inventory (paper naming)

This folder mirrors the dataset naming used in the paper to keep experiments and code references consistent.

- **D1 – Random streaming matrices (Exp. 1–3)**: `D1_random_streaming_matrices/` (`rand1`, `rand2`, `rand3`)
- **D2 – Software-curated signals (Exp. 1)**: `D2_software_curated_signals/ContinuousSine/` (sine + trigger, BIN)
- **D3 – Hardware sine wave (Exp. 1)**: `D3_hardware_sine_wave/` (no files; measurement-only)
- **D4 – SEREEGA evoked-potential datasets (Exp. 1)**: `D4_sereega_evoked_potentials/` (`ABR`, `ASSR`, `Oddball`, `VEP`, `SSVEP`)
