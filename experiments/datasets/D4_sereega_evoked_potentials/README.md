# D4 – SEREEGA evoked-potential datasets (Exp. 1)

Reproducible evoked-potential benchmarks exported as BIN + reference PDFs:
- `ABR/` (Waves I–V)
- `ASSR/` (40 Hz steady-state)
- `Oddball/` (N1–P2, P300)
- `VEP/` (N75–P100–N135)
- `SSVEP/` (10 Hz steady-state)

Each dataset folder contains `params.json` and one or more `.bin` files, plus EEGLAB reference PDFs used by Experiment 1.
