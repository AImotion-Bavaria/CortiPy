# plot_sine_bins.py

Back to [experiments overview](../README.md).

## Purpose
Plot precomputed average ERP and PSD signals stored as BIN files, handling different axis/data storage conventions.

## Inputs and data sources
- Required directory containing:
  - `sine_average.bin`
  - `sine_psd.bin`
- Optional axis bins:
  - `--time-bin` (time vector)
  - `--freq-bin` (frequency vector)

These BIN files are typically produced by other tools or external MATLAB/EEGLAB exports. The script attempts to infer axis/data if they are concatenated or interleaved.

## What the script does
1. Loads `sine_average.bin` and `sine_psd.bin` as float64 arrays.
2. Splits each array into axis and data using a heuristic:
   - If even length, try concatenated axis+data (first half axis, second half data).
   - If axis is not monotonic, fall back to interleaved axis/data.
   - If odd length or split fails, use optional external axis bins or a simple index axis.
3. Plots:
   - ERP vs time on the top panel.
   - PSD vs frequency on the bottom panel.
4. Optionally zooms the ERP plot to an initial time window (`--avg-window-s`).

## Outputs and plots
- Two on-screen matplotlib subplots (ERP and PSD).
- No files are written unless you save figures manually.
